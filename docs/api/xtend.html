upload_pb_attrs

def upload_pb_attrs(
    id:str='uploadprog'
):

Form hx_on progress attr that reveals and updates a hidden upload_pb of matching id

File uploads can take a while for large files, so it’s nice to show users a progress bar. With a progress bar like Progress(id='uploadprog', value='0', max='100', cls='hidden'), upload_pb_attrs returns an htmx event handler that reveals and updates it.

Add both to a form, along with htmx’s multipart encoding:

Form(Input(type='file', name='f'),
    Progress(id='uploadprog', value='0', max='100', cls='hidden'),
    Button('Upload'),
    hx_post='/upload', hx_encoding='multipart/form-data', **upload_pb_attrs())

As the browser uploads, htmx fires htmx:xhr:progress events carrying loaded and total byte counts. The handler waits for the first event that reports a total, then removes the hidden class and sets the bar’s value to the percentage uploaded.
